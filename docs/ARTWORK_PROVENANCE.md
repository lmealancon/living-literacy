# Artwork provenance

`prototype/web/hero-world.png` is an original character-free background generated
for the Living Literacy synthetic welcome-page prototype using an
image-generation tool. The prompt described a reading garden; it
did not request or include the names, characters, logos, or proprietary artwork
of any other platform. It is not a lesson or assessment asset.

The illustration is a new proposed brand/content asset for owner review before
publication. The software's AGPL-3.0-only license does not by itself establish
a separate artwork or trademark license. Record the owner's approval and any
separate content-licensing decision before treating the art as publicly
approved for reuse. The layered seed-like SVG character and its browser
animations were created for this project and remain subject to the same owner
review for branding and included content.
