# Codex Task 001 — Repository foundation

## Objective
Create a reproducible development foundation for Living Literacy using synthetic data only.

## Scope
- Initialize Next.js/TypeScript project with clear modular boundaries.
- Configure lint, format, unit testing and CI.
- Add responsive accessible black/gold design tokens and application shell.
- Configure migration tooling for proposed PostgreSQL use, without selecting production vendor.
- Document environment variables without secrets.
- Preserve specs and decision register in repository.

## Exclusions
No real student data, child registration, production auth, AI chat, scoring, diagnostic claims, audio provider integration, billing or live school features.

## Acceptance
Clean build, lint, tests, mobile/desktop smoke checks, no committed secrets, reproducible README, explicit change report. Codex must report actual commands and results; do not assert tests passed unless executed.

## Completion report
Files changed; commands and results; decisions required; next bounded task.
