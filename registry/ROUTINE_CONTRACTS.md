# Instructional routine contracts — source review required

Each routine must define: skill applicability, prerequisite task conditions, Activate/Model/Guide/Practice/Apply Independently/Review actions, adult script, student response, assistance recording, accessibility adaptation, and evidence limitations. Do not invent pedagogical scripts as reviewed material.

## Invariants
- Dependency guidance never blocks concurrent word-recognition and language-comprehension instruction.
- A lesson completed is not mastery.
- Audio modeling cannot be silently counted as independent decoding evidence.
- Only expert-approved lesson versions can be student-facing.
